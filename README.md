# KeyCode Manager

نظام عربي لإدارة اشتراكات ChatGPT وGemini وتصنيفها بين العملاء والمتاجر، ديون العملاء، الديون المستحقة عليك للوكلاء، الدفعات متعددة العملات، الإشعارات، والمستخدمين.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث. بيانات الدخول التجريبية:

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

تُحفظ البيانات محلياً في `localStorage` داخل المتصفح. أسعار الصرف المبدئية هي 1 دولار = 530 ريال يمني، و1 ريال سعودي = 139.7 ريال يمني.

عملة السداد الافتراضية هي الريال اليمني. عند اختيار خدمة Gemini ونوع «دعوة» يظهر حقل البريد الإلكتروني المستضيف تلقائياً.

يمكن إنشاء الدين بالريال اليمني أو الدولار أو الريال السعودي، ويحوّله النظام إلى رصيد يمني موحّد حسب أسعار الصرف القابلة للتعديل من القائمة الجانبية. حسابات المتاجر المفتوحة تُصدر تنبيهاً بعد 36 ساعة دون دفعة، ويبدأ توقيت جديد عند تسجيل أي دفعة جزئية.

يمكن إضافة مبالغ دين جديدة إلى حساب موجود، ويحتفظ سجل الحساب بكل إضافة مع عملتها وملاحظتها وتاريخها. كما يستطيع الزائر إرسال طلب إنشاء حساب من شاشة الدخول؛ يبقى الطلب معلّقاً ولا يُنشأ المستخدم إلا بعد موافقة المدير من صفحة المستخدمين.

## التخزين المحلي

كل متصفح وجهاز يحتفظ ببيانات مستقلة. لا تنتقل البيانات بين الأجهزة، وقد تُفقد عند حذف بيانات الموقع أو استخدام وضع التصفح الخاص؛ لذلك يُنصح بعدم مسح بيانات الموقع من المتصفح.
